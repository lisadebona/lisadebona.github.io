Step-by-Step Instructions

Set Up Email on Microsoft Outlook

Follow our clear, illustrated guide to quickly connect Microsoft 365, Gmail, Yahoo, iCloud, or custom domain accounts on your Desktop computer or Mobile phone.

Provider: Standard / Auto-Detect

Type your email above to automatically calculate your IMAP/SMTP hostnames and view customized step-by-step guides.

Select Operating System:
1

Launch Outlook & Add Account

Open Microsoft Outlook on your desktop. If this is your first time opening Outlook, a welcome setup wizard will open automatically.

// Manual path if already open:
File > Add Account (top-left menu bar)
2

Enter Email Address

Type your full email address: your-email@example.com

Custom Domain or Private Email Server? Check the box for "Let me set up my account manually" (Windows) or select "IMAP/POP" (Mac) under Advanced Options before clicking Connect.
3

Select Account Type

Choose your account protocol:

Microsoft 365 Auto-syncs everything
IMAP (Recommended) Syncs across multiple devices
POP3 Downloads locally to device
4

Enter Credentials & Server Settings

Enter password for your-email@example.com. Use these personalized hostnames:

Incoming Server: imap.example.com (Port 993, SSL)
Outgoing Server: smtp.example.com (Port 587, STARTTLS)
Username: your-email@example.com
2-Factor Auth Enabled? You may need to use an App Password instead of your regular password.

Finish & Sync

Click Done or Finish. Outlook will send a test message to verify the connection. Once validated, your inbox will begin synchronizing automatically.

Select Device Platform:
1

Install & Open Outlook App

Download Microsoft Outlook from the Apple App Store. Open the app once installed.

2

Add Account

Tap Add Account or tap your profile icon / menu (top-left) > Settings (Gear Icon) > Add Mail Account.

3

Enter Email & Authenticate

Enter your-email@example.com and tap Continue. If prompted, authenticate through your provider's sign-in screen.

If using custom IMAP, tap "Choose Account Type" manually or toggle advanced settings to enter hostnames and port numbers.
4

Permissions & Notifications

Allow notifications when prompted so you receive alert popups for new emails sent to your-email@example.com.

Ready to Use

Your email account is now configured! Tap your inbox to start composing and reading emails on mobile.

Target App: iOS Settings & Apple Mail
1

Open iPhone Settings

On your iPhone home screen, open the Settings app.

iOS 18 / 17 / 16: Settings > Apps > Mail > Mail Accounts
iOS 15 / 14: Settings > Mail > Accounts > Add Account
2

Tap 'Add Account' & Select Provider

Tap Add Account. You will see a list of major email providers:

iCloud
Microsoft Exchange
Google / Gmail
Yahoo
Aol.
Other (Custom IMAP)
3

Enter Name & Account Credentials

If your provider is listed, tap it and follow the web login prompt. If using a custom domain or private server, tap Other > Add Mail Account and fill in:

  • Name: Your full name
  • Email: your-email@example.com
  • Password: Password or App Password
  • Description: Name for this account (e.g., Work Mail)
4

Configure Server Hostnames (For 'Other' Accounts)

Select IMAP at the top, then enter both Incoming and Outgoing Mail Server settings:

Incoming Mail Server:
Host Name: imap.example.com | Username: your-email@example.com
Outgoing Mail Server (SMTP):
Host Name: smtp.example.com | Username: your-email@example.com

Select Sync Items & Save

Choose features to synchronize (Mail, Contacts, Calendars, Notes) and tap Save. Open the default Mail app icon on your iPhone to access your inbox.

Common Troubleshooting Solutions

Outlook keeps asking for password repeatedly

1. Ensure 2-Factor Authentication isn't blocking regular logins. Generate an App Password in your provider's security portal.

2. Go to Windows Credential Manager / Mac Keychain Access and delete stored credentials for Outlook, then re-enter them.

Can receive emails, but cannot SEND emails (SMTP Error)

1. Ensure SMTP Authentication is enabled under account settings ("My outgoing server requires authentication").

2. Verify SMTP port: Use 587 (STARTTLS) or 465 (SSL/TLS) instead of port 25 (which is blocked by most ISPs).

SSL / TLS Certificate Warning

This happens when your incoming/outgoing server domain (e.g. mail.yourdomain.com) doesn't match the SSL certificate installed on the server. Change hostnames to your server's primary domain (e.g. mail.hostingprovider.com).

iPhone Built-in Mail: "Cannot Connect Using SSL" Error

1. Go to Settings > Mail > Accounts and select the account.

2. Tap Account Settings > Advanced to verify SSL is toggled ON and the server port is set to 993 (IMAP) or 995 (POP).

3. Under Outgoing Mail Server (SMTP), tap the primary server name and verify SSL is enabled with port 587 or 465.

IMAP vs POP3 Quick Tip

Always prefer IMAP over POP3 if you access your email on more than one device (e.g. computer and phone). IMAP keeps actions synchronized across all devices.
