1

Configure Microsoft 365 SMTP in WordPress

Log into your WordPress Dashboard, install an SMTP plugin (such as WP Mail SMTP or FluentSMTP), select Other SMTP as your mailer option, and enter the following settings:

SMTP Host
smtp.office365.com
Encryption TLS / STARTTLS
SMTP Port 587
Authentication Enabled (ON)
SMTP Username your-email@yourdomain.com
SMTP Password Account Password OR App Password

Multi-Factor Authentication (MFA) Notice

If your Microsoft 365 user account has Multi-Factor Authentication (MFA/2FA) enabled, standard passwords will be rejected. You must generate an App Password through your Microsoft Security Info dashboard (mysignins.microsoft.com) and paste it into the password field above.

Important: "From Email" Matching Rule

Microsoft 365 forbids sender spoofing. The From Email address in your WordPress SMTP plugin settings must exactly match the Microsoft 365 mailbox username used for authentication. Check the box to Force From Email in the plugin settings.

2

Enable DKIM Signing in Microsoft 365

DKIM adds a cryptographic digital signature to outgoing email. This proves to recipient inbox providers (like Gmail and Yahoo) that the email genuinely came from your company domain.

  1. Log into the Microsoft Defender Portal using your administrator credentials.
  2. Navigate to Email & Collaboration > Policies & Rules > Threat Policies > DomainKeys Identified Mail (DKIM).
  3. Select your domain name from the list and toggle DKIM to Enabled.
  4. Microsoft will display two CNAME DNS records that must be added to your domain registrar.

Required DNS CNAME Records

Type Host / Name Value / Target / Points To Action
CNAME selector1._domainkey selector1-[yourdomain-com]._domainkey.[yourdomain].onmicrosoft.com
CNAME selector2._domainkey selector2-[yourdomain-com]._domainkey.[yourdomain].onmicrosoft.com

*Replace [yourdomain-com] with your domain name (replacing dots with hyphens) and [yourdomain] with your initial Microsoft 365 domain prefix as shown in your Defender dashboard.
